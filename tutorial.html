09

Web vs Desktop

Same notes, shortcuts, and account. Only the platform powers differ.

Runs anywhere

Web · PWA

  • Nothing to install — open the link
  • Installable; own window, works offline
  • Once installed, shortcuts match desktop — incl. Ctrl+T
  • In a plain tab, use Alt+T for timestamps
Maximum power

Desktop · app

  • Always-on-top overlay above your video
  • Global Ctrl+Alt+N to show / hide
  • Downloads embed-blocked videos to keep seek working
  • Native window controls
Blocked videos: some disable embedding. Desktop downloads a seekable copy; the web shows a note with a link to watch on YouTube. Everything else is identical.
